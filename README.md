#GISPR Module 2

This repository contains my Module 2 work fro GISPR. It uses Pierce county's 2010 Census Blocks data from the Pierce County open source Geospatial data portal to build a repeatable workflow which loads data, runs sanity check, classifies blocks by area, cleans tract codes, maps results, and saves the output.
